# 年份分隔与圆点留白

## 目标

大图时间线按年份清晰分段，日期圆圈只显示月日；竖线与圆圈、圆点保留舒适的间隔。

## 改动

- 在每个年份的第一个时间点前显示居中的「—— 2026 ——」年份分隔行，每个年份只显示一次。
- 从日期圆圈移除年份，保留月日、当前圆圈尺寸及与照片的间距。
- 竖线在每个圆圈和圆点上下留约 8 点空隙，仍沿卡片和时间差区域延伸，不直接接触标识。
- 时间差与距离差只显示数值，移除「距上一站」前缀；大图和小图模式保持一致。
- 无拍摄时间的照片不显示年份；小图模式保持原有日期显示，按日期跳转继续定位到时间点。
