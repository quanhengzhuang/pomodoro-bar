# 调整活动倒计时时间

## 目标

让活动倒计时既能增加时间，也能通过负数缩短时间。

## 改动

- 将菜单和弹窗从“延长时间”改名为“调整时间”。
- 接受 -180 到 180 之间的非零整数；正数增加，负数缩短。
- 同时调整剩余时间和本段计划时长，保持已过时间不跳变。
- 调整后剩余时间必须大于 0，否则显示校验提醒且不修改计时。
- 同步中英文 TODO 并勾选已完成项目。
