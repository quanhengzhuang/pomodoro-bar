# Mac 今日指引编辑框支持复制粘贴

## 目标

让 Mac 今日指引弹窗中的多行输入框支持标准复制、粘贴、剪切与全选快捷键。

## 改动

- 为菜单栏应用配置 AppKit 标准编辑菜单，将 ⌘C、⌘V、⌘X、⌘A 交给当前获得焦点的文本输入框处理。
- 保持今日指引 JSON 格式、保存行为、数据目录和计时逻辑不变。
- 构建并检查菜单配置；在可运行图形界面的环境中验证弹窗的快捷键。

## 影响文件

- `Sources/main.swift`
- 本任务中英文文档

## 预估代码行数

约 20–35 行。

## 结果

已为无主窗口的菜单栏应用设置标准编辑菜单，⌘X/⌘C/⌘V/⌘A 通过响应链交给当前输入框。`./scripts/build.sh` 通过；未启动 App 做界面测试，以免中断正在运行的计时，需在弹窗中手动验证快捷键。
