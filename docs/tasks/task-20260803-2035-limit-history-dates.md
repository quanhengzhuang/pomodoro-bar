# 限制历史日期菜单

## 目标

限制历史记录菜单长度，并在日期标题中显示周几。

## 改动

- 历史记录只展开最近 30 个有记录的日期。
- 日期标题显示为“YYYY-MM-DD 周X（共 X 条）”。
- 存在更早记录时，在历史菜单底部显示“更早记录（共 X 天）...”，点击后打开记录文件。
- 历史记录总天数和总条数仍显示完整数据统计。
