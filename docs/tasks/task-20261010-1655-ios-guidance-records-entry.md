# iOS 首页调整今日指引与专注记录入口

## 目标

首页直接显示今日指引；专注记录改为点击入口后查看。

## 改动

- 将首页“最近记录”区域改为今日指引内容，覆盖未设置、文件未选择和读取失败等状态，并提供明确的“修改”入口。
- 将摘要区原“今日指引”入口改为“专注记录”，点击进入独立记录列表；无记录时显示空状态，不删除或改写已有记录。
- 保留右上角引号入口及现有今日指引页面；复用现有 JSON 文件读写和计时记录数据。

## 影响文件

- `iOS/Pomodoro/Pomodoro/ContentView.swift`
- 本任务中英文文档

## 预估代码行数

约 90–140 行 Swift 增删。

## 结果

已完成：首页显示今日指引和“修改”入口，点击后直接进入今天的编辑状态；摘要区“专注记录”打开完整记录列表，右上角引号入口保留。未改动 JSON 或计时记录。iOS 通用真机构建与 `./scripts/build.sh` 均通过；未启动模拟器。
