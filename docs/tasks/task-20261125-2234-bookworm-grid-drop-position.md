# 明确书单格子的拖拽插入位置

## 目标

拖拽时让用户看清会插到目标书的前面还是后面，松手后的顺序与提示一致。

## 改动

- 将整格蓝色高亮改为插入线。格子左侧对应插到该书之前，右侧对应之后。辅助功能单列布局用上下两侧表示前后。
- 按插入线所在位置保存顺序，拖动方向不改变落点的含义。取消拖拽时清除插入线。

## 影响文件

- `iOS/bookworm/App/LibraryView.swift`

## 预估代码行数

约 45–90 行 SwiftUI 改动。

## 验证重点

从目标书的两侧发起拖拽，分别验证插到目标书前和后的结果。检查跨行移动、退出编辑和重启保留顺序。重新构建 iOS 真机版并覆盖安装，运行 `./scripts/build.sh`。
