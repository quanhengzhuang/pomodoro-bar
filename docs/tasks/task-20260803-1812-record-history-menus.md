# 今日与历史记录菜单

## 目标

将今日全部记录和历史记录拆成两个并列的二级菜单，历史记录再按日期提供三级菜单。

## 改动

- 将现有“全部记录”命名为“今日全部记录（共 X 条）”，继续显示当天全部记录。
- 新增“历史记录（共 X 天 / X 条）”二级菜单。
- 历史记录按日期倒序排列；每个“YYYY-MM-DD（共 X 条）”日期项作为三级菜单显示当天记录。
- 主菜单最近 10 条今日记录保持不变；无记录时显示对应的禁用占位项。

- 历史记录按日期倒序分组，每个日期作为三级菜单显示该日记录。
