# 时间线每日开始标识

## 目标

让跨天行程中每一天的开始一眼可辨，并用颜色提示较长或较短的时间差。

## 改动

- 按照片的拍摄日期，在每天第一张照片前显示醒目的日期分隔标识，包含完整日期、星期和行程第几天；大图、小图模式一致。
- 「第几天」按行程中实际有照片的日期顺序编号。
- 日期按设备当前日历和时区判断；没有拍摄时间的照片集中显示在独立的「待补录时间」分组。
- 保留现有时间顺序及跨天时间差显示；修改照片时间后，日期标识随时间线更新。
- 时间差超过 2 小时显示为警告黄色，少于 20 分钟显示为绿色；等于阈值及其余时间差沿用当前蓝色。大图、小图模式一致。
