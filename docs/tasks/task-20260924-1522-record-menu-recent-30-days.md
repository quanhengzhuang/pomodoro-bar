# 记录菜单展开今日并限定近 30 天历史

## 目标

今日记录全部直接显示在主菜单；历史记录仅显示近 30 个自然日，完整历史仍保留在 JSON 文件。

## 改动

- 移除“今日全部记录”子菜单及主菜单的 10 条限制，今日记录按原顺序全部展开。
- 历史菜单限定为今天之前的近 30 个自然日，不再按有记录的日期凑满 30 天；标题改为“历史专注记录（近 30 天 / xxx 条）”，条数只统计该范围内的记录；更早记录可通过“打开记录文件”查看。仅更改标题措辞，不额外按记录类型筛选。
- 保持“今日指引记录（近 30 天）”菜单标题及其历史内容与范围不变。
- 从主菜单移除“打开记录文件”，在“历史专注记录”和“今日指引记录”两个子菜单的最下方分别增加打开 `records.json` 和 `daily-guidance.json` 的入口；即使菜单暂无记录也可打开文件。
- 原“更早记录”跳转入口由历史子菜单底部的打开文件入口取代，文件仍保留全部日期。
- 不更改记录读写、格式或文件中的历史内容。

## 影响文件

- 本任务中英文文档

约 45–75 行增删。

## 结果

已完成：今日全部记录直接在主菜单展示；“历史专注记录”仅展示今天之前的近 30 个自然日并保留范围内条数，“今日指引记录”标题与范围不变；两个子菜单底部各自打开完整的 JSON 文件。没有更改记录格式或删除旧日期。`./scripts/build.sh` 构建通过（仅有现存通知 API 弃用警告）。
