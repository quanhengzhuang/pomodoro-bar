# 简化大图时间线卡片

## 目标

让大图卡片只显示必要信息，并能从地点直接打开系统地图。

## 改动

- 移除大图卡片中的编辑图标；点击照片、时间或备注进入编辑。
- 时间改为单行「年月日 时:分」，地点以较小文字接在右侧；空间不足时地点截断，完整地点仍可通过点击查看。
- 点击地点打开系统地图：有 GPS 时定位到坐标，没有 GPS 时搜索手动填写的地点。
- 没有备注时不显示占位文字；没有地点时不显示地点入口。保留缺少拍摄时间的补录提示。
- 让地点和卡片编辑分别响应点击，避免打开地图时误入编辑。
- 大图时间线每天第一张照片左侧用圆形日期标识（显示月/日，跨年时附年份），代替横跨整行的日期条；小图模式保留现有日期分隔，按日期跳转仍定位到每日开头。
