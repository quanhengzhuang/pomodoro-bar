# 今日指引记录

## 目标

在菜单的历史记录下方增加今日指引历史入口，可按日期查看最近 30 个自然日内的指引内容。

## 改动

- 在“历史记录”下方增加“今日指引记录”子菜单。
- 包含今天在内，仅展示最近 30 个自然日中内容非空的日期，并按日期倒序排列。
- 每个日期显示日期和星期，展开后使用现有 520 点宽的暖黄色斜体纯文本视图完整展示当天内容。
- 无记录时显示明确的空状态，不修改 `daily-guidance.json` 的格式或历史数据。
- 同步更新中英文 README。

## 实际变更

- 在专注记录的“历史记录”下方新增“今日指引记录（近 30 天）”子菜单。
- 按本地自然日筛选包含今天在内的最近 30 天，忽略空内容、无效日期、未来日期和更早数据，并按日期倒序展示。
- 日期菜单显示日期和中文星期，展开后复用 520 点宽的暖黄色斜体纯文本视图展示完整内容。
- 无符合条件的内容时显示“暂无今日指引记录”；中英文 README 已同步说明。
