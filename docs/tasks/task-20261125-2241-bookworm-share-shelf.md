# 书虫全书单图片分享

## 目标

在「我的书单」一键生成包含全部书籍的图片并打开系统分享，同时细化小组件的标题和封面样式。

## 改动

- 按当前列表或格子布局生成长图，沿用书单顺序。书单过长时按行拆为多张，封面暂不可用时仍展示书名和占位图。
- 分享过程显示生成状态，支持通过系统分享表单保存或分享图片。
- 小组件标题使用明确的中文粗字重，封面加细灰边与轻微明暗渐变。

## 影响文件

- `iOS/bookworm/App/LibraryView.swift`、新增长图渲染文件及其 Xcode 编译引用
- `macOS/WeReadShelf/Widget/ReadingWidgets.swift`

## 预估代码行数

约 190–300 行 Swift 和工程配置。

## 验证重点

确认长图包含屏幕外书籍、保留顺序，长书单可分张，两种布局均可打开分享。核对小组件标题字重和封面边缘。构建并覆盖安装真机版，运行 `./scripts/build.sh`。
