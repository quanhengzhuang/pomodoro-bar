# 书虫单张书单长图

## 目标

列表和格子均可把整个书单分享到同一张 PNG。

## 改动

- 按行分段绘制封面与文字，并将各段写入同一个 PNG 文件。整张图只显示一次标题和书籍总数。
- 分享面板只接收一个文件，取消或失败时清理临时文件。
- 格子页书名改用较小的字号，与长图在手机宽度下的视觉大小接近。

## 影响文件

- iOS 书虫的 BookListShare.swift、LibraryView.swift、PNG 写入文件和 Xcode 工程引用

## 预估代码行数

约 180–250 行 Swift 与工程配置。

## 验证重点

用超过原分页高度的大书单验证两个布局的首尾内容、书目顺序、PNG 解码和分享面板，编译安装真机版。
