# iOS 今日指引编辑聚焦与历史编辑

## 目标

让今日指引进入编辑状态后隐藏无关内容，并支持编辑和保存历史日期的指引；日期统一显示为「2026年9月17日 星期四」格式。

## 改动

- 编辑今日指引时隐藏历史列表和非编辑状态操作，突出当前编辑区域。
- 历史日期支持进入编辑状态、保存和取消，保留原有 JSON 日期键及其他日期内容。
- 统一今日和历史卡片的中文日期显示格式。

## 影响文件

- `iOS/DailyGuidance/DailyGuidance/ContentView.swift`
- `iOS/DailyGuidance/DailyGuidance/GuidanceStore.swift`
- `docs/en/tasks/task-20260918-1113-ios-guidance-edit-focus.md`

## 预估代码行数

约 100–160 行 Swift，少量 task 文档更新。

## 兼容与验证重点

- 不改变 `daily-guidance.json` 的日期键和整体格式。
- 编辑历史日期时只更新对应日期，不覆盖其他日期。
- 验证今日/历史编辑的保存、取消、文件不可写提示，以及中英文日期格式。

## 验证结果

- 今日与历史日期均可进入聚焦编辑状态；保存和取消后返回完整时间线。
- 保存逻辑按 `yyyy-MM-dd` 原日期键更新单条内容，JSON 仍使用原有格式并保留其他日期。
- 日期显示已统一为「yyyy年M月d日 EEEE」中文格式；iOS 16.1 目标源码类型检查及签名构建通过。
