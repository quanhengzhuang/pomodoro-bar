# 显示照片地点与相邻地点距离

## 目标

在时间线和时间点编辑页显示照片拍摄地点，并在时间差旁显示相邻照片的地点距离。

## 改动

- 从新导入及已有照片副本中读取 GPS 信息；有坐标时尝试转换成易读的城市、区县地名，失败时显示坐标。
- 在大图、小图卡片显示地点；编辑页允许手动填写或修改地点。没有 GPS、也未填写地点时不显示地点行。
- 相邻两个时间点都有 GPS 坐标时，在时间差旁显示两点直线距离；不足 1 公里用米，其余用公里。缺少任一坐标时只显示时间差。
- 每个时间点保存可选的地点信息；旧行程缺少该字段时仍可正常读取，原照片文件保持不变。
