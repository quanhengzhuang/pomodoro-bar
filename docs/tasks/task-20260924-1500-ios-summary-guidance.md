# iOS 首页摘要区加入今日指引

## 目标

将首页摘要区改为三块：今日指引（已设置/未设置）、原今日专注时间、原完成时段；移除最后的实时活动状态，并让今日指引块打开今日指引页面。

## 改动

- 保留现有摘要区视觉结构和两个计时统计值。
- 将第一块改为可点击的今日指引入口，未选择文件时沿用文件选择流程。
- 删除摘要区最后的实时活动状态块，右上角引号入口保留。

## 影响文件

- `iOS/DailyGuidance/DailyGuidance/ContentView.swift`
- 本任务中英文文档

## 预估代码行数

约 25–45 行。

## 结果

已完成。首页摘要区现在显示今日指引状态、今日专注时间和完成时段；移除了待开始的实时活动状态。今日指引摘要块和右上角引号入口共用打开逻辑，未选择 JSON 时仍进入文件选择流程。

构建验证：Xcode 模拟器及通用 iOS 构建均因当前环境 CoreSimulator 服务不可用（找不到模拟器 runtime）在资源编译阶段失败；尚未完成真机或模拟器界面检查。
