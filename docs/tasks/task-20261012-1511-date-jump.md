# 按日期快捷跳转时间线

## 目标

在照片较多的行程中快速跳到指定日期。

## 改动

- 在行程详情页导航栏加入「跳转日期」入口，列出行程中有照片的日期及「待补录时间」分组。
- 选择日期后滚动到对应日期标识；大图、小图模式都可使用，照片时间变动后列表自动更新。
