# 调整书虫 iPhone 书单布局

## 目标

让「最近阅读」和「我的书单」的格子更紧凑，列表中的封面、文字和操作按钮对齐。

## 改动

- 格子在常规字号下固定每行四本。缩小封面、使用直角，封面下方只显示一行书名，按参考图的比例采用约 13–14 pt 的中等字重，长书名末尾省略。辅助功能大字号沿用可读的单列布局。
- 列表书名只显示一行。作者、累计阅读时长和最近阅读日期统一为当前时长字号。封面按可见文字块的高度对齐，信息齐全时覆盖四行。右侧「…」与整行垂直居中。
- 去掉单独的时钟按钮。把手动刷新阅读时长放进操作菜单。格子和「最近阅读」列表通过长按打开菜单，「我的书单」列表可点「…」。书单的移动和移出确认继续通过菜单操作，点封面仍可打开微信读书。

## 影响文件

- `iOS/bookworm/App/LibraryView.swift`

## 预估代码行数

约 60–110 行 SwiftUI 改动。

## 验证重点

用长书名、完整四行和缺少阅读信息的样例在 iPhone 模拟器检查两套布局，并验证封面链接、长按菜单和移出确认。重新构建 iOS 模拟器版和真机版，运行 `./scripts/build.sh`。
