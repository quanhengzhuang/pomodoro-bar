# 正计时与倒计时

## 目标

番茄钟同时支持正计时和倒计时。

## 改动

- 「开始」改为正计时开始按钮；活动计时期间禁用，由「暂停/继续」接管空格快捷键。
- 运行中显示「暂停」和「结束」，不再显示「重置」。
- 删除「跳到下一段」。
- 「专注」「休息」不再显示选择标记，点击即开始对应倒计时。
- 倒计时运行时，「开始」不可点击；「暂停」「结束」仍可用。
- 提前结束时，达到 5 分钟记录；低于 5 分钟提示不记录。
- 未来菜单列表：
  - 状态：`专注/休息/正计时 · 未开始/运行中/已暂停 · 时间`
  - 开始
  - 暂停
  - 结束
  - 设置本段备注...
  - 专注 N 分钟
  - 休息 5 分钟
  - 长休息 15 分钟
  - 设置专注时长...
  - 今日完成...
  - 番茄外时间...
  - 最近 10 条记录
  - 全部记录（共 X 条）
  - 记录文件...
  - 清空记录
  - 退出番茄计时

## 实现前现状

- 仅支持专注、短休息、长休息倒计时。
- 「开始」只会启动或继续当前倒计时。
- 「重置」会清除当前进度，「跳到下一段」会直接切换模式，两者都不记录提前结束的计时。
- 只有自然完成倒计时才写入记录。

## 实际变更

- 新增从 `00:00` 开始累加的正计时，状态行区分「专注」「休息」「正计时」。
- 菜单改为独立的「开始」「暂停/继续」「结束」控制项；空格根据当前状态开始、暂停或继续。
- 「专注」「短休息」「长休息」点击后直接开始倒计时，活动计时期间禁止切换模式或再次开始。
- 删除「重置」和「跳到下一段」，结束当前计时时恢复到对应的未开始状态。
- 主动结束时，实际计时达到 5 分钟即写入记录；不足 5 分钟弹窗提示且不写入。
- 正计时记录使用新增的 `count_up` 类型，保存实际计时分钟数；原有 JSON 字段和旧记录解码逻辑不变。
- 正计时纳入当前活动时长计算，README 已补充功能和记录类型说明。
