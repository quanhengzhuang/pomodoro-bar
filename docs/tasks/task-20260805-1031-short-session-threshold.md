# 提前结束记录阈值改为 3 分钟

## 目标

将提前结束时不记录的时长阈值从 5 分钟改为 3 分钟。

## 方案

- 增加统一的最小记录时长常量，值为 3 分钟。
- 有效时长不足 3 分钟时继续弹出确认，确认结束后不写入记录。
- 有效时长达到 3 分钟时正常写入记录。
- 提示文案同步改为“不足 3 分钟”。

## 影响文件

- `Sources/main.swift`
- `docs/tasks/task-20260805-1031-short-session-threshold.md`
- `docs/en/tasks/task-20260805-1031-short-session-threshold.md`

## 复杂度

低；预估修改 5–10 行代码，不改变记录数据格式。

## 实际变更

- 新增统一的最小记录时长常量，设为 3 分钟。
- 提前结束不足 3 分钟时确认且不记录，达到 3 分钟时正常记录。
- 弹窗文案从 5 分钟同步更新为 3 分钟。

- `./scripts/build.sh` 构建成功，仅有既有通知 API deprecated 警告。
