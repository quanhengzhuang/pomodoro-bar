# 延长活动倒计时

## 目标

支持给活动中的倒计时增加分钟数，并将专注时长固定为 25 分钟。

## 改动

- 活动或暂停的专注/休息倒计时显示“延长时间...”。
- 输入框默认增加 5 分钟，允许输入 1 至 180 分钟。
- 同时增加剩余时间和本段计划时长，保持已过时间不跳变。
- 移除“设置专注时长”菜单、偏好读取与校验弹窗，专注固定为 25 分钟。
- 更新中英文 README 和 TODO。

## 实际变更

- 活动或暂停的专注、短休息、长休息倒计时显示“延长时间...”。
- 延长弹窗默认填写 5 分钟，校验 1 至 180 的整数。
- 增加剩余时间的同时增加本段计划时长，已过时间、提前结束时长和番茄外时间均保持连续。
- 正计时不显示延长入口。
- 删除专注时长设置菜单、偏好读取/写入和相关校验弹窗，专注固定为 25 分钟。
- 中英文 README 和 TODO 已同步更新。
