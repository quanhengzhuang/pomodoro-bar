# 菜单记录折叠展开

## 目标

当天记录太多时，菜单默认折叠，只显示最近几条，可手动展开全部。

## 改动

- 默认显示最近 5 条当天记录。
- 超过 5 条时显示“展开全部记录”；展开后显示“收起记录”。
- 展开状态仅保存在本次运行内，不写入数据文件。
