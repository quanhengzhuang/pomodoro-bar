# iOS 骰盘布局与逐骰投掷优化

## 目标

修正骰盘桌面显示不完整、骰子越界或凭空出现的问题，并让骰子逐个落下、落定后再显示对应结果。

## 改动

- 调整 3D 相机、骰盘比例和安全边界，保证完整桌面始终位于可见区域。
- 取消投掷过程中将骰子整体重新摆回桌面的做法，增加每枚骰子的独立投掷队列和落定状态。
- 每枚骰子在独立入场、碰撞和稳定后立即结算，全部骰子完成后再结束本次投掷。
- 保留减少动态效果、历史记录和 1–10 枚骰子布局。

- `iOS/DiceRoller/DiceRoller/DiceSceneView.swift`
- `iOS/DiceRoller/DiceRoller/ContentView.swift`
