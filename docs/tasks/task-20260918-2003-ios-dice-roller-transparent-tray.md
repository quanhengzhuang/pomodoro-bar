# iOS 骰桌透明容器与逐骰静止

## 目标

移除突兀的方形窗口视觉，让骰子在投掷前始终可见于桌面，并在桌面范围内逐个静止、逐个累加结果。

## 改动

- 去掉外层厚重的棕色窗口和装饰边框，改为透明/无边框容器，仅保留 SceneKit 的骰桌。
- 投掷开始时不隐藏或移走骰子；每枚骰子从当前桌面位置获得独立速度和旋转。
- 为每枚骰子增加独立静止判定，静止后立即回调结果并更新总点数；全部静止后写入一条历史记录。
- 加强桌面内的物理边界和超时保护，避免骰子离开可见桌面或瞬移回桌面。
