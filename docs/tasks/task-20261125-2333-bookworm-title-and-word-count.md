# 书虫页标题和字数补查

## 目标

略放大两个书单页顶部标题，并补充字数和阅读人数。

## 改动

- 放大「我的书单」与「最近阅读」的顶部标题，保持左对齐。
- 略微增加列表中的书名、作者和信息行字距。
- 优先使用单本详情的总字数。缺失时查询官方章节目录，仅在章节字数足以汇总时展示总数。
- 推荐值与「阅读 XXX 人」同一行，阅读人数按书籍 ID 匹配微信读书的数据。日期、时长和字数放在下一行，时长省略「累计」。
- 列表的封面打开阅读器，书名及下方文字打开微信读书详情。分享图同步处理日期行中新增的分隔线。
- 已缓存的缺失字数会补查，已有书单、时长和推荐值继续可读。

## 影响文件

- iOS 书虫的 LibraryView.swift、BookListShare.swift
- 共用的 WeReadAPI.swift 和 LibraryStore.swift

## 预估代码行数

约 100–160 行 Swift。

## 验证重点

覆盖已有总字数、章节补查、阅读人数的版本匹配、缺失和旧缓存，编译并安装 iPhone 版。
