# Refine Photo Timeline Cards

## Goal

Restore the large photo's display aspect ratio and simplify the card time and timeline date marker.

## Changes

- Show large photos in the earlier wide aspect ratio and enlarge date circles to show year, month, and day.
- Show only the time below photos; use the same font size and color for time and place, and increase the note font size.
- Remove the “since previous stop” prefix from elapsed times in both modes and center the elapsed time in large mode.
