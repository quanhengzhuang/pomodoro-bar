# Connect Timeline Markers

## Goal

Extend the vertical rail alongside each large photo card so it nearly meets adjacent date circles and point markers.

## Changes

- Draw the rail beside each card and join it with the interval segment, behind the circles and dots.
- Stop the rail at the final marker instead of leaving a dangling line beside the final card.
- Center the time-and-distance label across the width of its photo card; allow long text to wrap while staying centered.
- Preserve interval colors, date-circle size, photo aspect ratio, and compact mode.
