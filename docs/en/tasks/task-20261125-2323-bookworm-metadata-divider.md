# Bookworm metadata dividers

## Goal

Give separators less visual weight, enlarge titles slightly, and tighten spacing between books.

## Changes

- Use a lighter, shorter separator in both lists and shared images. Show it only between two available values.
- Use slightly larger titles and tighter row spacing in both lists. Keep a consistent cover size.

## Affected files

- iOS Bookworm's LibraryView.swift and BookListShare.swift.

## Estimated code size

About 25–40 lines of Swift.
