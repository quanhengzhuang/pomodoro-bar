# Translucent Live Activity Controls

## Goal

Make the buttons in the iOS Lock Screen Live Activity and expanded Dynamic Island closer to the system's translucent control style.

## Changes

- Adjust the background, border, and pressed feedback for Pause/Resume, Add Five Minutes, and End, while keeping End visibly distinct.
- Leave button actions, timer behavior, and records unchanged.

## Impacted Files

- `iOS/Pomodoro/PomodoroLiveActivity/PomodoroLiveActivity.swift`

## Estimated Code Lines

Approximately 10–20 lines of styling code.

## Validation Focus

Check contrast on light and dark Lock Screen backgrounds, the expanded Dynamic Island layout, and pressed feedback.
