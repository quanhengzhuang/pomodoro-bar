# Move Notes Above Photos

## Goal

Show notes above photos, reduce secondary text size, and use one color for elapsed times.

## Changes

- Show a note above the photo in large cards when present, in smaller regular text.
- Reduce the time and place type sizes in large and compact modes by one step.
- Use the normal theme color for intervals and timeline rails, removing the special colors for over two hours and under twenty minutes.
- Use the regular system typeface for page and trip titles instead of a serif typeface.
