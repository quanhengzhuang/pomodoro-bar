# Refine the iOS Home Guidance Card

## Goal

Give today's guidance a clearer reading hierarchy on the home screen while matching the text color of the existing guidance page.

## Changes

- Refine the card's title, muted date, body text, and Edit control with more deliberate spacing; use a restrained warm vertical rule beside the body.
- Reuse the existing guidance page's adaptive warm yellow for body text and action emphasis, while keeping empty and error messages readable.
- Leave guidance editing, the focus records entry, and data access unchanged.

## Affected Files

- `iOS/Pomodoro/Pomodoro/ContentView.swift`
- Both versions of this task document

## Estimated Code Lines

Approximately 35–60 lines of Swift added or removed.
