# Restore Large Photo Card Ratio

## Goal

Restore the display aspect ratio of large photos from before the circular date markers were added.

## Changes

- Reduce the layout width taken by the date marker so the photo card regains its former width while keeping the circular marker visible.
- Keep the photo height and saved crop positions unchanged.
