# Shorter centered Bookworm grid titles

## Goal

Show shorter titles centered beneath their covers in the grid.

## Changes

- Shorten the display title at common Chinese and English punctuation. Apply the same rule to the grid and its shared image.
- Center the single-line grid title beneath its cover. Keep the full title for the list and underlying book record.

## Affected files

- iOS Bookworm's LibraryView.swift and BookListShare.swift.
- WeReadShelf's ReadingModels.swift.

## Estimated code size

About 20–35 lines of Swift.
