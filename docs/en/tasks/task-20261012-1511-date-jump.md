# Jump to a Date in the Timeline

## Goal

Quickly reach a chosen date in a trip with many photos.

## Changes

- Add a “Jump to Date” control in the trip detail navigation bar, listing dates that have photos and the “Time needed” group.
- Scroll to the selected date marker. Support both large and compact modes and update the list when photo times change.
